처음 오신 분께 — 이 시리즈를 3줄로

  1. 무엇을 영화 별점은 표(관계형 DB)에 잘 들어가는데 리뷰 문장의 "뜻"은 왜 표로 찾기 어려운지 확인하고, 뜻을 숫자 좌표로 바꿔 저장·검색하는 벡터 DB를 만들어 LLM·RAG까지 잇습니다.
  2. 왜 중요한가 회사 데이터의 대부분은 문장·사진처럼 정해진 항목이 없는 데이터입니다. 생성 AI가 회사 문서로 답하게 하려면(RAG) 벡터 DB가 거의 반드시 들어갑니다.
  3. 업무에서는 "벡터 DB 도입" 기획서를 읽고 무엇을 저장하고, 무엇을 묻고, 무엇으로 채점할지 물을 수 있게 됩니다.

코드·수식을 몰라도 됩니다. 모든 장에 직접 움직이는 실험 도구가 여러 개 있고, 수식은 조수 하루가 하나씩 물어봅니다.

벡터 DB 인포그래픽의 그림 아홉 개 — 이 시리즈 어디서 다루나

벡터 DB를 한 장에 정리할 때 흔히 쓰는 아홉 개 그림(정의, 임베딩, 유사도 검색, 색인, 메타데이터 필터, 작업 흐름, 거리 재는 법, 관계형 DB와 비교, RAG)을 이 시리즈가 어디서 다루는지 모았습니다. 본문에서 "○번 그림"이라고 하면 이 표의 번호입니다.

인포그래픽 그림이 시리즈직접 해 보는 실험
1. 벡터 DB란 (임베딩을 저장·검색)1장 전체, 3-1SQL 실습실, 레코드 미리보기
2. 임베딩 (뜻을 담은 고차원 좌표)2-1, 2-2낱말 세기 vs 뜻 좌표, 임베딩 해부실
3. 유사도 검색 (가장 가까운 이웃)2-3, 2-4화살표 두 개, 의미 검색기
4. 색인 (HNSW, IVF, 근사 검색)3-2, 3-3서랍 색인, 길 찾기 그래프
5. 메타데이터 필터3-4, 4-5좌표 + 표 조건, 날짜 필터
6. 작업 흐름 (넣기 → 상위 k개)3장, 4-2, 6-1RAG 시뮬레이터, 3D 창고 지도와 프롬프트 줄
7. 거리 재는 법 (코사인·유클리드·내적)2-3, 2장 대결세 가지 자, 코사인 vs 내적
8. 벡터 DB vs 관계형 DB1장, 3-5, 5-4어디에 저장할까, 도입 판단 도우미
9. RAG4장, 5-3, 6장, 7-3조각 크기, 하이브리드 검색, 기억 창고, 어텐션 3D, GraphRAG

      데이터와 원칙

      데이터 (모두 가상)내용
      영화 8편 · 리뷰 483개별점 1~5점과 리뷰 문장. 리뷰마다 "무엇을 좋다·나쁘다고 했나"(재미·감동·공포·연기 등) 이름표가 있어 검색을 채점합니다. 비꼬는 리뷰 3개 포함
      SNS 글 139개 (14일)영화 이야기·음식·날씨·일상, 말만 바꾼 광고(둘째 주에는 처음 보는 말투 포함), 9일째부터 늘어나는 결제 오류 이야기
      랩플릭스 안내 문서 12개 · 질문 16개가상 OTT 서비스의 요금제·환불·해지·오류 코드 안내. 환불 규정은 구버전·현행 두 판. 질문 중 2개는 문서에 없는 질문
      교육용 임베딩사람이 뜻을 정한 289개 낱말, 24차원(차원마다 "재미", "감동" 같은 이름). 실제 임베딩 모델(384~1,536차원, 이름 없음)의 원리를 눈으로 보이게 만든 설명용입니다
      • 모든 숫자는 페이지가 브라우저에서 직접 계산하고, 같은 계산을 code/analysis.js가 data/results.json에 남깁니다.
      • LLM이 문장을 쓰는 부분(4·5장)은 미리 적어 둔 답으로 흉내 냅니다. 찾기·점수·채점은 실제 계산입니다.
      • 연결 강좌: 데이터베이스 설계(표·SQL·정규화), 인공지능과 자연어 데이터 분석(자연어의 특징·임베딩·LLM).
